# Changelog

## v1.0.1 Beta — 2026-10-23

- Updated Android application identity to com.resumetrics.app and set Android version code 2 / version name 1.0.1.
- Refined the ResuMetrics logo and Android launcher icon assets.
- Improved mobile preview layout, resume template browsing, zoom behavior, and page presentation.
- Built and verified signed Android APK and AAB artifacts; installed the APK as an in-place update on a physical Android device.

### Known limitation

On Android, **Save PDF** opens the native print framework and displays an A4 resume preview. **Share PDF** currently opens the same print UI rather than a dedicated Android share sheet. The direct-share workflow remains under development.

This is a beta build; inspect generated PDFs before sending important job applications.
